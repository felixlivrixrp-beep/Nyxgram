# Nyxgram — Telegram для ПК с призраком и сохранением удалённых сообщений

Nyxgram это настоящий Telegram Desktop с дополнительными функциями. Он собран на основе открытого проекта
[AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) (это форк Telegram Desktop) с новым названием и иконкой.
Выглядит и работает как обычный Telegram, ваши чаты и аккаунт те же.

## Что в нём есть (из AyuGram)

- 👻 **Режим призрака**: не отмечает сообщения прочитанными, скрывает «в сети» и «печатает», настраивается по пунктам.
- 🗑 **Удалённые сообщения** остаются в чате с пометкой.
- ✏ **История правок** сообщений.
- Отправка сообщений «по расписанию» в призраке, сохранение даты прочтения и последнего визита, переводчик, фильтры сообщений, настройка шрифтов и внешнего вида и многое другое.
- Новое имя **Nyxgram** и новая иконка.

## Чего пока нет

- **Сохранения самоуничтожающихся фото/видео и сообщений с таймером.** В AyuGram этого нет, а писать такую функцию в Telegram Desktop без возможности её собрать и проверить я не стал, потому что ошибка в коде ломает 3–5 часов сборки. Это следующий шаг: когда у вас будет готовая сборка, я добавлю функцию отдельным патчем.
- Версий для телефона и macOS. Сборка настроена только на Windows x64.

## Как получить Nyxgram.exe (без программирования)

Сборка идёт на бесплатных серверах GitHub, вам нужен только аккаунт на github.com.

1. Зарегистрируйтесь на https://github.com (если нет аккаунта).
2. Нажмите **+ → New repository**, назовите, например, `nyxgram`, выберите **Public** (для бесплатной сборки репозиторий должен быть публичным) и создайте его.
3. Распакуйте этот архив. В созданном репозитории нажмите **uploading an existing file** и перетащите в окно **всё содержимое** распакованной папки: папки `.github` и `nyxgram`, а также `README.md`. Нажмите **Commit changes**.
   Если папка `.github` не загрузилась (она скрытая), создайте файл вручную: **Add file → Create new file**, в имени напишите `.github/workflows/build-windows.yml` и вставьте туда содержимое одноимённого файла.
4. Откройте вкладку **Actions**. Если GitHub просит, нажмите зелёную кнопку, разрешающую запуск.
5. Слева выберите **Build Nyxgram (Windows x64)** → **Run workflow**. Режим оставьте `Debug` для первого запуска.
6. Ждите. Первая сборка занимает **несколько часов** (собираются все библиотеки Telegram), потом можно закрыть страницу. Повторные запуски быстрее благодаря кэшу.
7. Когда рядом появится зелёная галочка, откройте этот запуск и внизу, в разделе **Artifacts**, скачайте `Nyxgram-Windows-x64-Debug`. Внутри лежит `Nyxgram.exe`. Установка не нужна, просто запустите.
8. При первом входе введите номер телефона и код, как в обычном Telegram.

### Debug или Release

`Debug` собирается быстрее и надёжнее, но файл большой и программа работает медленнее. `Release` быстрее в работе, но собирается примерно вдвое дольше и может упереться в лимит времени GitHub (6 часов). Начните с Debug.

### Свои ключи Telegram API (по желанию)

По умолчанию используются общие ключи из инструкции по сборке AyuGram. Лучше завести свои: на https://my.telegram.org → *API development tools* создайте приложение, затем в репозитории **Settings → Secrets and variables → Actions → New repository secret** добавьте `TG_API_ID` и `TG_API_HASH`.

## Что если сборка упала

Откройте красный запуск, найдите красный шаг и скопируйте последние 30–40 строк лога. Пришлите их мне, я исправлю. Я не мог запустить эту сборку у себя (нужен Windows и несколько часов), поэтому первая попытка может потребовать правки.

## Важно знать

- Это неофициальный клиент. Ответственность за его использование на вашем аккаунте на вас; сохранение чужих сообщений без ведома людей может нарушать закон вашей страны.
- Берите Nyxgram.exe только из собственной сборки. Чужие «готовые» моды с таким же названием могут красть аккаунты.
- Исходный код Telegram Desktop и AyuGram распространяется по лицензии GPL v3, поэтому репозиторий должен оставаться открытым, а авторство AyuGram и Telegram сохраняется (оно указано в настройках приложения).

## Что делает патч

`nyxgram/apply_nyxgram.py` запускается на свежих исходниках AyuGram Desktop (закреплена проверенная версия) и меняет только видимое: название приложения, тексты интерфейса, свойства файла `.exe` и иконки. Внутренние названия и логика не трогаются.
